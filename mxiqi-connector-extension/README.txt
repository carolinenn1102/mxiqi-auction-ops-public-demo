麦稀奇采集助手（Chrome）

安装：
1. 解压 mxiqi-connector.zip。
2. Chrome 地址栏打开 chrome://extensions/。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 mxiqi-connector-extension 文件夹。
5. 回到送拍业务工作台，打开“平台登录”，点击“检查真实登录”。

使用：
- 麦稀奇账号登录只在 https://www.mxiqi.com/ 官方页面完成。
- 扩展不保存账号、密码、验证码或 Cookie。
- 工作台只从扩展接收订单字段，并保存在当前浏览器本地。
- “待发货”同步最快；“最近订单”最多读取最近 5 页。

如 Chrome 显示扩展 ID，应为：dkomiogcdcldejbdenlhhnhfedcjkipo
