麦稀奇采集助手（Chrome）
版本：1.9.0

安装：
1. 解压 mxiqi-connector.zip。
2. Chrome 地址栏打开 chrome://extensions/。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 mxiqi-connector-extension 文件夹。
5. 回到送拍业务工作台，打开“平台登录”，输入麦稀奇账号密码并点击“登录并抓取待发货”。

使用：
- 工作台把本次输入的账号密码交给扩展后，扩展只会向 https://www.mxiqi.com/ 官方登录页提交。
- 扩展不保存账号、密码、验证码或 Cookie。
- 密码提交后会立即从工作台输入框清空。
- 工作台只从扩展接收订单字段，并保存在当前浏览器本地。
- “待发货”同步最快；催款使用“待付款”；结算复核先读取待付款，再按所选期数读取“成交目录”。订单状态最多读取 20 页，“最近订单”最多读取最近 5 页。
- 导入寄存表后，可按寄存单号精确搜索历史麦稀奇订单并回补拍品、买家和收件资料。
- 1.6.0 新增按拍卖期数读取成交目录并匹配 Lot 的结算能力；升级时请在 chrome://extensions/ 中删除旧版或点击“重新加载”。
- 1.7.0 新增真实物流连接状态检查、顺丰企业寄件入口，并明确阻止未配置接口时生成假运单。
- 1.8.0 结算同步会依次检查所有已打开的麦稀奇标签页，避免因为选错页面而误报“找不到成交目录”。
- 1.9.0 结算同步会按工作台所选期数自动进入“实时专场 → 数据 → 成交目录”，无需人工先打开目录，并可直接读取麦稀奇成交表格。
- 如果结算同步提示未找到拍场，请确认工作台选择的期数与麦稀奇实时专场中的期数一致。
