# 送拍运营工作台 · 公开体验版

独立静态工作台，可选配本地 Chrome 采集助手连接麦稀奇；暂不连接正式物流接口。

体验地址：<https://carolinenn1102.github.io/mxiqi-auction-ops-public-demo/>

- 数据保存在访问者浏览器的 `localStorage`
- 支持送拍跟踪表、麦稀奇模板、寄存记录、送评记录和外拍当前库存导入
- 外拍工作簿只读取“整体”当前库存，不把“已售出”误导入库存
- 拍品可录入送拍人手机号，并按手机号、订单号、评级编号或拍品名称搜索
- 寄存/库存会优先按手机号自动匹配此前订单；不能唯一确定时进入人工确认
- 人工匹配结果、寄存/库存资料和拍品一起进入完整备份
- 支持固定金额/百分比佣金、客户生日月优惠和网页结账复核
- 支持按送拍人、拍场、状态和拖回处理筛选
- 可按送拍人及时间段汇总，全部结账后导出 Excel 或结算明细图片
- 支持超时未付款提醒，以及拖回/发回、再拍、等待和拆单状态
- 支持手动单次刷新、15 秒至 5 分钟自动刷新和闲置自动停止
- 支持在工作台输入麦稀奇手机号和密码，登录成功后立即抓取并显示真实待发货订单
- 账号密码只由本地采集助手提交到麦稀奇官方登录页，提交后输入框立即清空，源码、本地存储和备份均不保存凭证
- 仍支持自行打开麦稀奇官网登录，再回到工作台检查现有会话
- 支持快速同步待发货订单，以及最多 5 页最近订单；自动刷新固定使用待发货范围以减少请求
- 工作台和采集助手都不收集或保存真实密码、验证码、Cookie 或接口密钥
- 没有安装采集助手时仍可使用明确标识的演示连接和演示调度
- 已付款订单会进入发货待办，展示地址待二审、可下单、单号待回填和已完成状态
- 原始收件地址可拆分为姓名、手机号、省、市、区和详细地址；缺项会拦截下单，人工修正后二次确认
- 地址通过后可模拟菜鸟/顺丰下单，复制带 `DEMO` 标识的出库运单号，并记录麦稀奇回填状态
- 支持完整 JSON 备份、恢复和已访问页面的离线打开
- 物流与麦稀奇回填均为演示状态机，不会调用真实平台
- 真实客户资料只保存在当前浏览器，不会写入公开仓库；不要在公用电脑导入，也不要录入账号或接口密钥

## 本地采集助手安装

1. 从“平台登录”下载 `mxiqi-connector.zip` 并解压。
2. Chrome 打开 `chrome://extensions/`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择 `mxiqi-connector-extension` 文件夹。
4. 回到工作台，打开“平台登录”，输入麦稀奇手机号和密码，点击“登录并抓取待发货”。

该目录用于 GitHub Pages 临时公开访问。真实订单数据仍只保存在客户当前浏览器，不会提交到公开仓库。
