# 送拍运营工作台 · 公开体验版

独立静态体验站，不连接正式数据库或物流接口。

体验地址：<https://carolinenn1102.github.io/mxiqi-auction-ops-public-demo/>

- 数据保存在访问者浏览器的 `localStorage`
- 支持两种 Excel 导入与导出
- 支持固定金额/百分比佣金、客户生日月优惠和网页结账复核
- 支持按送拍人、拍场、状态和拖回处理筛选
- 可按送拍人及时间段汇总，全部结账后导出 Excel 或结算明细图片
- 支持超时未付款提醒，以及拖回/发回、再拍、等待和拆单状态
- 支持完整 JSON 备份、恢复和已访问页面的离线打开
- 物流流程仅生成带 `DEMO-` 前缀的模拟码
- 不应录入真实客户隐私、账号或接口密钥

该目录用于 GitHub Pages 临时公开体验，正式系统仍使用 D1 和服务端接口。
