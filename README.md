# 送拍运营工作台 · 公开体验版

送拍业务工作台，可选配本地 Chrome 采集助手连接麦稀奇，并通过独立服务器物流网关接入顺丰、菜鸟正式接口。

正式地址：<http://118.31.121.156/>

- 数据保存在访问者浏览器的 `localStorage`
- 支持送拍跟踪表、麦稀奇模板、寄存记录和外拍当前库存导入；寄存工作簿的“送评”附表暂不读取
- 外拍工作簿只读取“整体”当前库存，不把“已售出”误导入库存
- 拍品可录入送拍人手机号，并按手机号、订单号、评级编号或拍品名称搜索
- 寄存表的“用户”按买家处理，完整保留收货地址；不会再误写成送拍人
- 寄存库存按买家手机号/账号合并，买家置于第一列；展开后查看全部寄存物品，可整组标记发货并自动移到列表底部
- 可按寄存单号精确搜索麦稀奇历史订单，回补拍品、买家、完整收件地址、拍卖期数和日期
- 人工匹配结果、寄存/库存资料和拍品一起进入完整备份
- 支持固定金额/百分比佣金、低价固定佣金、生日返佣、多档 NP 优惠和网页结账复核
- 盒子关键词和成交门槛均可配置；命中生日月后负佣金会实际增加应结金额
- 拖回/再拍、拖回/发回、拖回/等待按可配置的每 Lot 扣费进入结算
- 支持按送拍人、麦稀奇标题中的拍卖期数、拍品状态和已发货/未发货筛选
- 结算复核按送拍人汇总其全部拍品、拍卖期数/日期、成交额、佣金和应结金额；已结清送拍人按实际点击结账的先后顺序排列，刷新后保持不变；导出表保持相同分组
- 支持明显的批量发货、批量删除和批量结账入口
- 支持超时未付款提醒，以及拖回/发回、再拍、等待和拆单状态
- 待付款订单可从麦稀奇独立同步，在买家信息后以单独“拍品状态”列展示；未超时显示“待付款”，超时后自动变为“超时未付款”
- 侧边栏提供“拖回再拍库”，集中保存拖回/再拍记录，并统计送拍人及扣费结算进度
- 支持手动单次刷新、15 秒至 5 分钟自动刷新和闲置自动停止
- 支持在工作台输入麦稀奇手机号和密码，登录成功后立即抓取并显示真实待发货订单
- 账号密码只由本地采集助手提交到麦稀奇官方登录页，提交后输入框立即清空，源码、本地存储和备份均不保存凭证
- 仍支持自行打开麦稀奇官网登录，再回到工作台检查现有会话
- 支持最多 20 页待发货、待付款和待确认订单，以及最多 5 页最近订单；完成整段同步后会清理已经离开“待付款/待发货”的旧状态并刷新顶部统计
- 同一麦稀奇订单的多件拍品会合并为一个包裹，默认收起；展开后可查看全部 Lot，并可整包选择、地址复核和共用一个出库运单
- 工作台和采集助手都不收集或保存真实密码、验证码、Cookie 或接口密钥
- 没有安装采集助手时仍可使用明确标识的演示连接和演示调度
- 已付款订单会进入发货待办，展示地址待二审、可下单、单号待回填和已完成状态
- 原始收件地址可拆分为姓名、手机号、省、市、区和详细地址；缺项会拦截下单，人工修正后二次确认
- 地址通过后可向服务器物流网关提交真实顺丰/菜鸟订单；接口未配置完整时会明确拦截，不生成 `DEMO` 运单号
- 支持完整 JSON 备份、恢复和已访问页面的离线打开
- 顺丰使用丰桥开放接口，物流密钥、月结卡号和产品编码只保存在服务器环境变量；浏览器只保存当前标签页的物流操作授权码
- 真实客户资料只保存在当前浏览器，不会写入公开仓库；不要在公用电脑导入，也不要录入账号或接口密钥

## 本地采集助手安装

1. 从“平台登录”下载 1.9.3 版 `mxiqi-connector.zip` 并解压。
2. Chrome 打开 `chrome://extensions/`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择 `mxiqi-connector-extension` 文件夹。
4. 回到工作台，打开“平台登录”，输入麦稀奇手机号和密码，点击“登录并抓取待发货”。

该目录用于 GitHub Pages 临时公开访问。真实订单数据仍只保存在客户当前浏览器，不会提交到公开仓库。

## 真实物流网关

服务入口为 `logistics-gateway/server.mjs`，同一服务同时托管网页和 `/api/logistics/*`。正式下单具备资料校验、操作授权、频率限制、同一包裹幂等保护和真实运单回填；失败不会被标为成功。

顺丰网关默认使用沙箱环境，按当前丰桥应用的“简易 MD5”方式签名，并支持正式下单与按客户订单号查询。沙箱统一使用顺丰测试月结卡号，不会触发真实取件。切换生产前必须在服务器配置 `SF_ENVIRONMENT=production`、已绑定的月结卡号、顺丰小件协议产品编码、实际付款方式，并显式设置 `SF_ALLOW_LIVE_ORDERS=true`；缺少任一项都会拦截下单。菜鸟正式启用前，需要菜鸟开放平台应用的 AppKey、AppSecret、商家寄件接口权限和接口文档。登录手机号、登录密码、短信验证码不能替代开放接口凭证，也不得写入项目文件。
